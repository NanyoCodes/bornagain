# **App Name**: Testify Global

## Core Features:

- Testimony Sharing: Allow believers to share testimonies through a social media-style feed.
- Campaign Creation: Enable users to create and join soul-winning campaigns with goal tracking and location-based features.
- Progress Tracking: Provide tools for users to log souls won, track personal evangelism efforts, and set goals with visual charts.
- User Profiles: Create extended user profiles with bios, locations, statistics, achievements, and inline editing.
- Automated Content Moderation: Employ AI-driven content moderation tools to ensure testimonies and campaigns adhere to community guidelines and promote a safe environment. The AI tool can use reasoning to remove the undesired part or the entire post.
- Multi-Language Support: Offer language selection and timezone configuration to make the platform accessible worldwide.
- Authentication: Integrate secure authentication methods like Email/Password, Google OAuth, and Facebook OAuth for user login.

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF) to symbolize hope and inspiration.
- Background color: Very light cyan (#E0FFFF), nearly white, creating a serene backdrop for content.
- Accent color: Coral (#FF806A) to draw attention to key actions and elements.
- Body and headline font: 'PT Sans' for a blend of modern style and readability.
- Code font: 'Source Code Pro' for displaying code snippets, enhancing the tech-savviness of the platform.
- Use clear and symbolic icons, related to faith and community, sourced from Lucide React.
- Subtle and meaningful animations to enhance user interaction and engagement, like a gentle pulse on Like and Share buttons.
